Project Overview

The Squirtle Smart Garden is an ESP32-powered automated watering system designed to monitor environmental conditions and water plants automatically when needed.

The system monitors temperature, humidity, and water level while controlling a pump through a MOSFET module.

This project combines 3D printing, electronics, soldering, programming, and web development into one complete engineering project.

Design Journey

How the project evolved from the original concept into the final Squirtle design.

Original Ladybug Design

The project originally began as a ladybug-themed smart garden. The concept was creative, but the internal space was limited, making it difficult to fit the reservoir, pump, wiring, and sensors cleanly.

Design Evaluation

After reviewing the first design, I realized it would be difficult to maintain and modify. I redesigned the project to improve component access, water routing, stability, and reliability.

Final Squirtle Design

The Squirtle design provided more internal room, better component placement, and a stronger visual theme. This made the project more functional, easier to assemble, and better suited for future upgrades.

System Architecture

The ESP32 acts as the main controller for the sensors, pump system, and dashboard.

How It Works

The temperature and humidity sensor measures the surrounding environment.

The water level sensor checks if the reservoir has enough water.

The ESP32 processes the sensor readings and controls the pump based on the system logic.

The website displays the system status so the project can be monitored through a browser.
