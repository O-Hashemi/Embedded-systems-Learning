# Embedded-systems-Learning
Hands on learning of embedded systems using Arduino compatible hardware.

Goals:
- Build a strong foundation in embedded systems
- Learn mircocontrolling programing C/C++
- Sensors, displays, interface, and acutators 
- Document learning

Hardware:
- Arduino/ Arduino compatible (Elegoo UNO R3)
- Breadboards and discrete components
- I2C devices (OLED/LCD)
- Sensors (temperature, ultrasonic, buttons, etc)

Learning Roadmap:
- Arduino Setup and Blink
- Digital I/O (LEDS, buttons)
- Analog I/O (potentiometers, senors)
- Timers and delays
- I2C communication
- Displays (LCD/OLED)
- Mini Porjects
